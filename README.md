## [Agent Rewind](https://github.com/chenpingan-dev/agent-rewind)

**A replay button for your Codex sessions**

Follow a failed call back to its input and output. Spot repeated work. Compare what changed in the next run.

[Open a recording →](https://chenpingan-dev.github.io/agent-rewind/) · [Install](https://github.com/chenpingan-dev/agent-rewind#replay-a-session) · Python

[![Agent Rewind session replay](https://raw.githubusercontent.com/chenpingan-dev/agent-rewind/main/assets/screenshot.png)](https://chenpingan-dev.github.io/agent-rewind/)

## [Patch Orbit](https://github.com/chenpingan-dev/patch-orbit)

**See where a Go change travels**

Turn a Git diff into a map of connected Go packages. Follow the import chain, inspect the source lines and take a checklist into your review.

[Explore the map →](https://chenpingan-dev.github.io/patch-orbit/) · [Download](https://github.com/chenpingan-dev/patch-orbit/releases) · Go

[![Patch Orbit dependency map](https://raw.githubusercontent.com/chenpingan-dev/patch-orbit/main/assets/screenshot.png)](https://chenpingan-dev.github.io/patch-orbit/)

Both tools run locally and save portable HTML reports. Online workspaces use labeled synthetic data and support 中文 / English.
