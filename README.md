## Projects / 项目

| Project                                                            | What you can explore                                                                                         | Try it                                                        |
| ------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------- |
| **[JSON Lens](https://github.com/honggege957-collab/json-lens)**   | A JSON workbench with tree exploration, JSON Pointer and structural diff / 看清 JSON 结构与变化           | [Live demo](https://honggege957-collab.github.io/json-lens/)  |
| **[Flow Atlas](https://github.com/honggege957-collab/flow-atlas)** | A dependency planner with critical-path analysis and a worker timeline / 理解依赖、关键路径与并行排期     | [Live demo](https://honggege957-collab.github.io/flow-atlas/) |

| **[Data Sieve](https://github.com/honggege957-collab/data-sieve)** | Python CSV validation with explicit rules and precise findings / CSV 规则校验与问题定位 | [Python CLI](https://github.com/honggege957-collab/data-sieve#try-it) |
| **[Pulse Probe](https://github.com/honggege957-collab/pulse-probe)** | Go HTTP diagnostics with request-stage timings and connection reuse / HTTP 耗时诊断与连接复用 | [Go CLI](https://github.com/honggege957-collab/pulse-probe#run-locally) |
