# Profile visuals

The profile uses a dark navy cover, high-contrast type and product-specific illustrations

- Agent Rewind: a session track with a selected call, in warm orange
- Patch Orbit: a package dependency graph, in blue
- Trace Parcel: selected requests and a report, in violet

The illustrations explain each tool's purpose; they are not screenshots or usage statistics

## Rendering

- All artwork is editable SVG, with no scripts, embedded fonts or external dependencies
- SVG typography prefers Microsoft YaHei, followed by Segoe UI and Arial
- GitHub controls the README's body typography and table styles
- The cover has English and Chinese variants, plus a larger-type composition for narrow screens
- Below 600px, project illustrations switch to compact symbols through native `picture` elements
- Keep real repository and workspace links in the README, outside the cover image

## Content

Keep the six project entries and both language versions in sync

Lead with concrete uses: session replay, Go dependency review and HAR reports

Use action labels such as Open replay, Explore dependencies and Prepare a report

Avoid internal priority labels, Demo or Example calls to action, artificial star counts and unverified adoption claims
